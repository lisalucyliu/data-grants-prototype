# Data grants prototype

This is a clickable concept prototype of the data grants pages in a data exchange console. It is inspired by AWS Data Exchange. I rebuilt it from my original wireframes.

This is not an AWS product. It is not affiliated with or endorsed by Amazon Web Services. Every company, product, person, and account ID in it is fictional.

## Live site

https://lisalucyliu.github.io/data-grants-prototype/sent-data-grants.html

## What you can try

- See the data grants you've sent, and search, sort, and page through them.
- Show or hide expired data grants.
- Create a data grant and watch its job finish in the activity history.
- Select data grants and choose to view, revoke, or delete them.
- See the data grants you've received and accept a pending one.
- Open the help panel on each page.

## Design system

The prototype follows the Cloudscape Design System.

## How it is built

I designed and built it with Claude Code. It uses plain HTML, CSS, and JavaScript. There is no build step and no server code. To run it locally, open `sent-data-grants.html` in a browser.
